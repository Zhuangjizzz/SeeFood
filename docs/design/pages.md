# 核心页面设计

本文维护页面布局、控件位置和状态呈现。共用视觉与完成条件见[页面设计入口](README.md)，卡库与文字交流见[沟通卡设计](communication-cards.md)；业务规则及验收用例由[功能规格](../product/functional-spec.md)维护。

<a id="entry"></a>

## 首次进入与拍照首页

功能依据：[首次使用](../product/functional-spec.md#21-首次进入与主导航)、[图片输入](../product/functional-spec.md#3-图片输入与提交)；验收 D01、D14。

- 首页内嵌简短说明和可跳过的偏好邀请，保留明显的语言入口。系统语言未匹配时的选语言流程按功能规格执行。
- 欢迎文字和桌面静物占用紧凑区域；菜单／菜品模式、拍摄、相册导入在首屏可见。
- 最近记录最多显示三条，并提供“查看全部”进入历史。条目的缩略图、名称和状态沿用[历史列表](#history)的呈现。
- 相机不可用时在输入区域说明情况，保留相册操作；没有记录时用简短说明引导首次拍摄或导入。

## 提交前预览

功能依据：[功能规格 3.2](../product/functional-spec.md#32-提交前预览)；验收 D02、D03、D06。

采用编号纵向图片列表。每行包含可点开大图的缩略图、编号、移除操作与独立拖动手柄；排序、移除和查看各自具有明确操作区域。

- 顶部标明新建记录或追加当前记录；追加时显示目标记录。
- 底部固定显示本批剩余图片数量与确认操作。空批次禁用提交，取消入口保持可达。
- 关闭大图后继续显示原预览列表；本批材料、顺序和位置按功能规格恢复。
- 拖动时呈现当前移动项与落点，避免误触图片查看或提交。拖动反馈、空列表和上传中断需分别核对画面。

## 提交后的进度

功能依据：[上传与处理](../product/functional-spec.md#33-上传处理与失败)、[本机保存](../product/functional-spec.md#81-自动保存与容量不足)、[退出恢复](../product/functional-spec.md#83-离开页面与退出恢复)；验收 D05–D07、D10。

确认后在结果页按图片展示待上传、上传中和各处理阶段；已可用内容保留浏览入口，失败项就近提供对应重试操作。

上传未完成时持续呈现上传提示；只有满足功能规格的整批接收条件后，才显示“可以退出、稍后回看”的说明。本机保存状态单独显示，处理成功但保存失败时，两种状态都应清楚可见。

## 结果页与图片区

功能依据：[功能规格第 4 节](../product/functional-spec.md#4-结果浏览与菜品详情)；验收 D04、D05、D15。

页面从上到下分为图片浏览区、当前图片关联的菜品卡片区、固定“问 AI”入口。图片浏览区提供缩略图选择、原图／译图切换、当前图片预览和添加照片；卡片可进入菜品详情，详情保留原图核对入口。

```text
当前记录
├─ 图片浏览区
│  ├─ 缩略图选择、原图／译图切换
│  ├─ 当前图片预览（点击全屏）
│  └─ 当前图片状态、添加照片
├─ 当前图片关联的菜品卡片
│  └─ 点击进入详情，可回原图核对
└─ 固定“问 AI”入口
```

原译首显、每图选择记忆和后台完成后的展示规则由[功能规格 4.1](../product/functional-spec.md#41-图片与卡片浏览)维护。处理、失败、无须译图与保存状态贴近当前图片呈现，避免混淆不同图片。

需覆盖卡片先完成、译图仍在处理或失败、当前图无卡片、无须译图等画面。菜品内容层级、未知信息与饮食提示按[功能规格 4.2](../product/functional-spec.md#42-菜品内容与详情)呈现，具体卡片样式留待后续细化。

## 全屏图片

功能依据：[功能规格 4.1](../product/functional-spec.md#41-图片与卡片浏览)；验收 D04。

- 首次打开按可用宽度适配，并从图片顶部开始阅读；长图支持纵向滚动，原图与译图均可放大核对。
- 顶部提供当前图片编号／总数、原图／译图选择、切换图片和关闭入口。
- 结果页与全屏共用当前图片及原译选择；关闭后恢复来源位置，继续浏览同一记录。
- 提交前预览的大图只显示待提交原图，不出现译图控件。

## 我的与语言设置

功能依据：[语言](../product/functional-spec.md#22-语言切换与内容保留)、[偏好](../product/functional-spec.md#6-饮食偏好与提示更新)、[本机数据](../product/functional-spec.md#8-保存离线恢复与删除)。

顶部紧凑显示已保存的实际偏好摘要，点击摘要进入编辑；未设置时显示简短邀请。下方集中放置历史记录、语言设置和本机数据说明，偏好入口保持单一。

语言设置呈现当前选择与支持的语言，完成后回到发起入口。本机数据区说明已保存内容与已有管理去向，操作范围沿用功能规格。

## 历史记录

功能依据：[历史与离线](../product/functional-spec.md#82-历史与离线回看)、[删除与清空](../product/functional-spec.md#84-删除与清空)；验收 D07、D09–D12。

- 每条显示首张图片缩略图、记录名称、日期时间和图片数量。名称使用可确认信息，例如“菜单＋日期”。排列顺序与离线可读范围按功能规格执行。
- 处理状态与本机保存状态分开显示，一条记录可以同时呈现处理完成与部分内容保存失败。
- 点击条目打开结果；单条删除位于条目“…”菜单，清空位于“管理”入口，执行前清楚呈现确认范围。
- 空列表提供拍摄／导入入口；待上传、处理中、保存失败与离线状态保留各自适用的操作和可读内容。

## 饮食偏好

功能依据：[功能规格第 6 节](../product/functional-spec.md#6-饮食偏好与提示更新)；验收 D13。

一页按“过敏信息 → 饮食限制 → 口味偏好”排列三组，每组分别提供选项和文字补充，底部统一保存。首次设置提供跳过入口；再次编辑显示已保存的选择与补充。

保存反馈与相关提示的“检查中／检查失败”分别呈现，填写中的内容保持编辑状态。具体过敏原与宗教饮食选项仍需内容核验。

## 独立聊天

功能依据：[功能规格第 5 节](../product/functional-spec.md#5-ai-对话与快捷建议)；验收 D08、D13、D14。

- 用户消息采用靠右气泡，回答采用较宽正文，减少头像、闪光标记与装饰。菜品引用和可收藏沟通卡放在对应回答内。
- 底部输入框配合发送操作，快捷建议位于输入框上方。回复中、部分回复、失败与重试各自有可辨状态；失败片段旁保留重试入口。
- 正在阅读旧内容时，在可见位置提供“有新回复”入口；阅读位置和草稿恢复、底部跟随行为按[功能规格 5.2](../product/functional-spec.md#52-回复状态与重试)执行。
- 核对键盘弹起、长回答、引用卡片、旧推荐待确认和输入状态的画面，确保正文与发送操作可达。

## 导航与返回

底部导航为“拍照／沟通卡／我的”。以下表格定义页面入口与返回关系，记录与浏览状态的保存规则见[功能规格 2.1](../product/functional-spec.md#21-首次进入与主导航)、[5.2](../product/functional-spec.md#52-回复状态与重试)、[8.3](../product/functional-spec.md#83-离开页面与退出恢复)。

| 发起位置 | 进入位置 | 返回或取消 |
| --- | --- | --- |
| 拍照入口 | 提交前预览 | 回拍照入口 |
| 结果页“添加照片” | 携带当前记录的预览 | 回原结果页 |
| 首页最近记录／历史条目 | 对应结果页 | 回实际来源列表及原位置 |
| 结果页 | 菜品详情／全屏图片／独立聊天 | 回来源视图及原位置 |
| 提交前预览 | 待提交图片全屏 | 回同批预览及原位置 |
| 首页／我的 | 语言或偏好设置 | 回实际发起入口 |
| 沟通卡 | 卡片展示／创建编辑／文字交流 | 按[沟通卡设计](communication-cards.md)返回 |

返回只恢复浏览，不重新提交处理。页面稿需覆盖目标记录已删除、原位置失效等情况，给出稳定的回退位置。
