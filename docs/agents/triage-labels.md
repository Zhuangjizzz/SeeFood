# 问题分流标签

技能使用五种标准的问题分流类别。本文件将这些类别映射为本仓库问题跟踪系统中实际使用的标签名称。

| mattpocock/skills 中的标签 | 本仓库问题跟踪系统中的标签 | 含义 |
| ------------------------- | ------------------------ | ---- |
| `needs-triage` | `needs-triage` | 需要维护者评估此问题 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求说明完整，可交给无人值守智能体（AFK agent）执行 |
| `ready-for-human` | `ready-for-human` | 需要由人来实现 |
| `wontfix` | `wontfix` | 不予处理 |

当技能提到某个分流类别时，例如“添加适合无人值守智能体处理的分流标签”（原文为 "apply the AFK-ready triage label"），使用本表中对应的实际标签名称。

根据实际使用的标签名称，调整“本仓库问题跟踪系统中的标签”这一列。
