# 沟通卡与文字交流页面设计

本文维护卡库、给店员展示、创建编辑和双向文字交流的布局与手势。分类、顺序、草稿及交流内容的保存规则见[功能规格第 7 节](../product/functional-spec.md#7-个人沟通卡与双向文字翻译)；共用视觉与多语言要求见[页面设计入口](README.md#视觉方向与多语言)。

<a id="library"></a>

## 个人卡库

### 分类与卡面

顶部提供“全部／饮食需求／餐桌沟通”筛选及当前分类的卡片数量，下方展示卡片。预置、自建与收藏卡片统一呈现，具体分类和顺序由[功能规格 7.1](../product/functional-spec.md#71-卡库与排序)维护。

- 卡面突出卡片自身语言的标题与正文，中文作为次要对照，颜色辅助辨认。
- 以纸边、柔和分层阴影和轻微厚度表现实体卡片；收展时同一组卡片连续移动，形成一叠或展开排列。
- 展开时分类与数量栏保持可见，右侧放小巧的收拢箭头，并留出足够点击区域。
- 每张展开卡右上角的“…”菜单提供编辑与删除；收拢时隐藏管理控件，卡面主体用于展示。卡库不设“展开卡片”按钮。

### 手势与反馈

| 当前状态 | 操作 | 预期呈现 |
| --- | --- | --- |
| 收拢 | 单击可见卡片 | 放大该卡，进入给店员看的单卡展示 |
| 收拢 | 长按卡片 | 当前卡叠连续展开 |
| 展开 | 单击卡片 | 放大所选卡片，进入单卡展示 |
| 展开 | 重新长按并上下拖动 | 呈现抬起、占位和排序反馈，松手完成排序 |
| 展开 | 点击收拢箭头 | 卡片连续收回一叠 |
| 单卡展示 | 返回 | 回卡库并接续原来的浏览状态 |

收拢时的一次长按仅展开；松手不能触发展示，必须在展开后重新长按才能拖动。普通上下滑动用于滚动浏览；拖动结束、取消拖动、菜单操作和箭头操作都不能额外触发卡面单击。长按时长、移动阈值、边缘滚动与取消反馈需在触控环境核对。

本轮实现使用 420ms 长按阈值；长按成立前移动超过 10px 后，本次手势继续滚动，不再提起卡片。展开卡片间距为 400rpx，拖动越过半个间距后切换落点。拖动进入滚动视口上下 48px 时，每 32ms 最多滚动 18px，到列表边界停止。分类、数量、收拢入口和拖动取消操作留在固定顶部。

触摸取消、多指触摸、主动取消、切换分类、收拢、离开页面均撤销尚未落下的移动，恢复上次顺序。移动后松手才整体保存；落点未变不记为完成排序。保存失败显示已恢复原顺序，并保留本次顺序的重试入口。上述参数已覆盖公开操作测试，实际触控、视觉与性能仍按本页检查项核对。

首次提示放在卡叠附近，使用当前界面语言：

- “轻点展示，长按展开”：非按钮说明，成功展开后隐藏。
- “长按卡片可调整顺序”：首次展开后出现，完成一次拖动后隐藏。

首次默认状态、重新进入卡库和切换分类的恢复规则由[功能规格 7.1](../product/functional-spec.md#71-卡库与排序)维护。切换分类时保持原有收展形态，不重新播放完整展开动画；保存顺序失败时明确反馈并保留重试入口。

<a id="display"></a>

## 给店员展示

采用竖屏单卡，大部分空间留给放大的中文，卡片自身语言对照放在下方。中文卡片只显示一份相同内容；长正文可以完整阅读。

保留清晰的返回入口，编辑和删除通过卡库管理菜单完成。展示与返回均不改变卡片顺序。

## 创建与编辑

页面按“你想说的话 → 生成并核对中文 → 保存”排列。内容输入在前，中文对照可检查和编辑；标题、分类与颜色放在内容下方。

| 新建字段 | 初值 |
| --- | --- |
| 标题 | 取卡片自身语言正文的开头，允许改写 |
| 分类 | 沿用具体分类入口；从“全部”进入时默认“餐桌沟通” |
| 颜色 | 浅绿 |

这些初值不依赖 AI 推断。编辑页载入已有文字与语言，语言切换按[功能规格 2.2](../product/functional-spec.md#22-语言切换与内容保留)处理。

表单提供草稿恢复、自动保存状态、主动“保存”和“放弃草稿”入口。草稿与正式卡片的生命周期及创建／编辑／收藏后的去向由[功能规格 7.2](../product/functional-spec.md#72-创建编辑收藏与草稿)维护，界面反馈必须与实际保存结果一致。

新建入口位于卡库介绍下方，可从任一分类进入 `/pages/card-editor/card-editor`。发现已有新建草稿时，先显示原语言、正文预览、“继续草稿”和“放弃草稿”；继续后恢复原来的文字、分类与颜色。未完成草稿不计入卡库数量。

展开卡片的管理菜单通过 `?id=<cardId>` 进入同一编辑页，载入这张卡当前的完整正文、语言、标题、分类和颜色。有该卡的未完成修改时，先显示“继续草稿”和“放弃修改”；其他卡片及新建草稿分别保留。未编辑预置卡以进入编辑时的界面语言载入，保存后成为固定语言的个人内容；既有标题不随正文编辑自动替换。

编辑保存成功后返回实际归属分类，保持全局顺序并定位刚保存的卡片；该卡不在分类首位时展开卡库使其可见。放弃修改保留原正式卡，单卡展示重新读取最后成功保存的内容。目标卡已删除时提示并返回卡库。上一个草稿写入失败时，先提供保存重试再打开另一个编辑目标，避免显示错卡或丢失尚在页面内的输入。

新建标题默认使用正文开头的最多 32 个字符，合并空白；用户改写标题后，正文变化不再覆盖该标题。颜色提供浅绿、浅蓝、浅橙。草稿固定使用创建时的内容语言，页面标签随当前界面语言切换。中文内容只保留一个正文输入区，不显示重复中文生成区。

| 新建状态 | 呈现与操作 |
| --- | --- |
| 正文或中文为空 | 保留输入与辅助字段；不允许保存空卡片 |
| 正在生成中文 | 显示等待说明，已有文字继续可读；正文仍可编辑 |
| 正文修改后 | 不自动翻译；已有中文保留供核对，重新生成或手动修改中文后才允许保存 |
| 生成失败或离线 | 保留原文和已有中文，显示对应原因；未确认接收的原请求提供“继续翻译” |
| 自动保存或正式保存失败 | 保留当前页面草稿、显示失败与重试入口；不能标为已保存卡片 |
| 本机读取失败 | 暂停编辑，先重新读取既有草稿，避免覆盖 |
| 保存成功 | 返回卡库的实际归属分类，新卡位于第一张；正式卡片可离线展示 |

表单随内容纵向滚动，保存按钮固定在底部并预留安全区；正文与中文输入按内容增高，分类和颜色按钮允许换行。五语言文案、页面绑定、磁盘与 HTTP 状态已经纳入公开接口测试；模拟器键盘、布局、安全区与实际触控由集成任务统一检查。

## 双向文字交流

顶部以“我说／店员说”切换说话者，共用主要输入区，并显示当前翻译方向。下方分别呈现双方最近一组“原文＋译文”，最新结果更突出。

切换说话者、未发送草稿、暂离恢复与主动清空按[功能规格 7.3](../product/functional-spec.md#73-双向文字交流)执行。提供“清空本次交流”入口，仅展示当前交流，不增加历史列表。

再次输入、生成中、成功替换、失败和离线分别呈现状态；等待新结果时仍可核对已有内容。清空后的空白反馈与迟到结果处理保持一致，不能重新展示已清空交流。

## 状态与触控核对

页面结构与主要操作已确认，以下画面与参数需在实现前定稿，并随[验收 D17](../product/functional-spec.md#9-本轮开发验收用例)检查：

- 空卡库、单卡、长列表和长正文，管理入口可达。
- 收展过程、拖动抬起与占位、边缘滚动、取消拖动，手势不串触。
- 草稿与正式保存的各类反馈，分类变化、删除当前卡片和恢复位置失效后的定位。
- 文字交流的新输入、等待、替换、失败、离线与清空画面。
- 五语言排版、卡片厚度、间距和动效节奏，以及键盘、安全区与触控尺寸。
